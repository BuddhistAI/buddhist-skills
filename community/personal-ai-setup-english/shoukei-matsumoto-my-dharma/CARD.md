# my-dharma.md (Shoukei Matsumoto's version)

**What it is:** a personal file that one Buddhist practitioner gives to the AI he works with. It is his own reading of the Dharma, which he and the AI both act under. It covers how they speak to each other, how they take correction, what the AI does and what he keeps for himself, and when to stop. It is not a set of commands, and it is not a template.

**Who it is for:** anyone who wants to see how one practitioner brings Buddhist practice into daily work with an AI.

## How it is used

The file is shared with the AI the author works with, so that both act under it. With Claude, a file like this can be added as a project file or a `CLAUDE.md`, so it is read in every conversation. The person writes the file; the AI may propose changes but does not make them. Changes are recorded in the file's own changelog.

The author's own words on copying it: copy it whole, root included, and live with it for a while; change a line when it starts to feel wrong. The file is in [my-dharma.md](./my-dharma.md), exactly as the author shared it.

## Limits

This is one person's reading, written in 2026. It is not a teaching of any one tradition, and we do not suggest that anyone should write a file like it. The notes "in AI terms" describe AI as it was in 2026 and will age.
