# Glossaries

One TSV per language pair, named `<source>-<target>.tsv` with ISO 639 codes (for example `bo-en.tsv`, `sa-en.tsv`, `pi-en.tsv`).

Columns:

```
source	preferred	alternatives	notes	added_by
```

- `alternatives` is a `|`-separated list.
- `notes` explains context or which tradition or organization prefers which rendering.
- `added_by` names the contributing organization.
